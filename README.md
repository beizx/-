# Beizx的阅读器 v1.3.0

本地优先的 **TXT / EPUB 小说阅读器**，使用 Flutter 构建，支持 Android 与 iOS。阅读是主角，翻译是一个随时可用的附加功能。

- **阅读优先**：导入的 `.txt` / `.epub` 自动解析章节、保存到本地书架，不联网也能读
- **两种阅读模式**：上下滚动阅读；自动分页的左右翻页阅读（像纸质书）
- **沉浸式阅读**：默认隐藏工具栏与系统栏；点击正文呼出/收起，左右滑动翻页或换章
- **阅读设置面板**：外观（模式、四种背景、衬线 / 无衬线、字重）、排版（字号、行距、段间距、首行缩进、四向边距）、操作（点击翻页、翻页动画、两端对齐、保持常亮、隐藏状态栏、时间 / 章节 / 进度 / 页码指示）
- **章节与书签**：目录支持搜索、当前章节高亮、译文标记；书签可添加、查看、跳转、删除
- **精确进度**：记录到章节内的滚动位置或页码，并在书架「继续阅读」与书籍详情恢复；同时累计每本书的阅读时长
- **可选翻译**：整书中 / 日 / 韩 / 英互译，接口未配置也不影响阅读
- 多语去重、TXT / EPUB 导出、密钥安全存储等 v1.1–v1.2 能力全部保留

完整产品设计与版本更新日志见 [deepseek.md](deepseek.md)。

## 视觉主题

继续沿用深蓝紫夜色，不改品牌色：深靛蓝黑背景 `#141221`、紫色卡片 `#211D3A`、雾白紫正文 `#F4F1FF`、鸢尾浅紫强调色 `#B9ACFF`。阅读器默认使用「夜色」皮肤，同时保留纸白 / 羊皮 / 护眼三种阅读背景；正文/背景对比度约 16.6:1，关键文本均达到 WCAG AA。启动器图标与印章 Logo 同步改为「读」，保留原有紫色印章外观。

### Windows 中文路径说明

当前 Flutter / Gradle 工具链在 **项目路径包含中文** 时存在两个已知限制：

1. `flutter analyze` 的分析服务可能崩溃；
2. Android 的 Dart AOT 构建可能无法读取中文路径下的 `app.dill`。

代码、Gradle 配置已加入 `android.overridePathCheck=true`。如果构建仍失败，请运行随项目提供的构建脚本——它会把源码同步到纯 ASCII 的暂存目录完成构建，再把 APK 复制回来：

```powershell
powershell -ExecutionPolicy Bypass -File .\tool\build_android.ps1
```

> 目录联接（junction）和映射磁盘仍会被 Flutter 还原成中文真实路径，不能绕过 AOT 限制；暂存目录必须是真实的纯 ASCII 路径。脚本默认使用 `%LOCALAPPDATA%\Temp\translation_app_build_ascii`，并从 `pubspec.yaml` 自动读取版本号生成 APK 文件名。

构建产物位于 `artifacts/BeizxReader-v1.3.0.apk`，同时复制到 `build/app/outputs/flutter-apk/app-release.apk`。

> 当前 `release` 构建沿用 Flutter 模板的 debug 签名，仅供本地安装与测试。正式上架 / 分发前，请在 `android/app/build.gradle.kts` 中配置自己的 keystore 签名。

## 阅读与阅读器

### 导入与上架

导入 TXT / EPUB 后，文件解析内容保存在应用本地并立即出现在封面书架。点按封面进入书籍详情；长按封面可直接开始 / 继续阅读。

### 书库与详情

- 书库按封面网格排列，可筛选 TXT / EPUB；顶部保留最近阅读的「继续阅读」卡片。
- 书籍详情改成阅读优先：先展示「继续阅读 / 开始阅读」与全书进度、累计阅读时长、书签数；章节列表列出前 8 章，可展开全部章节；翻译设置与多语去重下移为工具区。
- 阅读进度使用 `progress.json` 保存，精确到章节内位置；删除书籍时一并清理进度与书签。

### 阅读器手势

- **默认沉浸**：打开时只有正文和底部时间 / 章节 / 进度指示；点击正文呼出顶部与底部工具栏，再次点击收起。
- **滚动阅读**：上下滚动当前章节；左右滑动切换上一章 / 下一章。
- **翻页阅读**：把当前章节按屏幕、字号、行距和边距自动分页；左右滑动或点击左 / 右区域翻页；在章节首页 / 末页继续翻会进入上一章 / 下一章。
- **中间点击**：呼出或收起工具栏。翻页模式下工具栏显示时可长按选择、复制正文（此时横向滑动让位于选择手势，可用底部上一页 / 下一页按钮翻页）。
- **目录 / 书签**：顶部列表按钮打开「阅读导航」，可搜索章节、跳转、查看当前章节；「书签」分页可添加当前位置、跳转或删除。
- **原文 / 译文**：存在译文时右上角出现胶囊开关，切换后按相同阅读位置重新排版。
- **阅读设置**：底部「设置」按钮打开外观 / 排版 / 操作三个分页，所有改动即时生效并保存在本机。

### 阅读设置项

| 分类 | 项目 |
| --- | --- |
| 外观 | 滚动 / 翻页模式、夜色 / 纸白 / 羊皮 / 护眼背景、衬线 / 无衬线、字重、屏幕常亮、隐藏状态栏、时间 / 章节名 / 进度 / 页码指示 |
| 排版 | 字号 14–28、行距 1.4–2.8、段间距 0–28、首行缩进 0–2 字、左右边距、上边距、下边距 |

设置从底部导航「设置 → 阅读偏好」进入全屏版；阅读器内的设置面板与全屏版共用同一套组件。

### 翻译（可选）

翻译是附加功能，不配置接口也能完整阅读。配置后可在书籍详情选择源 / 目标语言并开始整书翻译；译文与原文共用同一阅读器，按章节缓存到本地。

## 多语去重

适用于「上一段日语原文、下一段中文译文」这类双语对照书籍。

1. 打开书籍详情，点击顶部筛选图标或「多语去重」工具卡；
2. 选择保留语言：中文 / 日语 / 英语 / 韩语；
3. 查看疑似对照组，逐组勾选或取消，可查看全文；
4. 选择「仅加入书库」或「生成并导出」，后者可导出 TXT / EPUB 去重文件。

识别在本地完成，不调用翻译接口，也不上传文本。判定依据是**相邻段落 + 语言脚本 + 长度比例**，结果属于“疑似对照”，不保证语义完全等价；请通过预览和勾选控制误删。当前只处理相邻段落，不处理同语言内部重复或远距离重复。

## 有道智云 API

1. 访问 <https://ai.youdao.com/> 注册账号；
2. 创建应用并开通「文本翻译」服务；
3. 在 App 的「设置 → 翻译接口」中填入 **App ID** 与 **App Secret**；
4. 点击「测试连接」，成功后保存。

密钥仅保存在本机安全存储中。翻译时只会将分段正文发送给你配置的翻译服务，不上传整书到任何自建服务器。免费额度、QPS 与计费规则以有道智云官网为准。

## 扩展新语言 / 新引擎

- **语言**：在 `lib/models/language.dart` 注册表中加入语言与各引擎的 provider code，选择器自动生效。
- **引擎**：实现 `lib/services/translation/translation_engine.dart` 的 `TranslationEngine`，并在接口设置页注册配置卡即可；翻译协调器不依赖具体服务商。

## 已知边界 / 路线

- v1.3 先完成本地阅读器本体；**网络书源下载**与**听书 TTS** 尚未接入，是下一阶段的方向。
- 翻页模式在工具栏显示时启用文本选择；此时横向滑动可能被选择手势占用，可用底部按钮或收起工具栏后滑动翻页。
- 滚动 / 翻页模式的分页基于 Flutter `TextPainter`，极端特殊字体或系统字体缩放可能带来 1–2 行的视觉差异。
- 当前 Android release 包沿用 debug 签名，仅用于本地安装测试。
